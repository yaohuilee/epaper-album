# Web 控制台

[文档首页](README.md) · [项目首页](../README.md)

界面由固件内置HTML/CSS/JavaScript提供，无外部CDN依赖。总体为顶部Header、左侧菜单、右侧工作区，采用24列栅格和8px间距基础。

## 页面分工

| 菜单 | 工作区 | 地址 |
|---|---|---|
| 设备管理 | 设备概览 | `/#overview` |
| 设备管理 | 网络与时间 | `/#network` |
| 设备管理 | 环境与供电 | `/#environment` |
| 相册管理 | 照片库 | `/albums#photos` |
| 相册管理 | 播放设置 | `/#playback` |

Header显示连接状态和设备时间。侧栏底部提供“切换下一张”、当前相册、当前照片和下次换图。名称过长时单行省略，悬停查看完整内容；点击当前照片可打开预览。

工作区宽度足够时卡片并排，窄屏上下排列。播放设置在工作区达到900px时双栏。767px及以下侧栏改为抽屉，导航抽屉可通过遮罩或Esc关闭。

## 卡片与设置

设备概览、环境与供电及照片库的刷新位于工作区标题右侧。网络与时间的操作按功能放在对应卡片右上角：Wi-Fi设置/刷新，校时设置/立即同步/刷新。

播放设置三张卡片展示已保存的相册选择、停留时间和夜间暂停。点击右上角设置进入独立弹窗，各项单独保存。网络设置也通过弹窗编辑。

夜间暂停弹窗提供Switch开关和每15分钟一档的起止时间选择，预设22:00–06:00。开始早于结束显示“当天”，晚于结束显示“跨午夜”和“次日”；两者相同禁用保存。已有其他分钟值标注“已保存”并原样保留。时间与Header的设备时间一致，暂停自动换图，手动切换仍可用。

设置弹窗只保留一个标题，右上角X无外框，撤销和保存位于底部右侧。Esc和点击遮罩不关闭弹窗。关闭不保存，草稿在当前页面中保留；撤销恢复设备值，重新加载清空草稿。后台轮询不覆盖草稿。

结果使用浮动提示，不推移工作区内容。成功自动隐藏，失败保留可关闭；弹窗打开时提示显示在弹窗内。

## 照片库与预览

照片库按资源管理器方式先展示相册文件夹，打开后同页展示照片和上传面板。管理目录与轮播选择相互独立。列表每页50张，筛选作用于本页文件名。

照片预览按窗口宽高完整适配图片，提前保留照片比例占位。只保留右上角X关闭，不设底部关闭按钮，不产生不必要的滚动条。左右箭头按相册自然顺序浏览，首尾不循环；预览不改变设备播放位置。

换图进度直接显示在固定高度的侧栏按钮上，三行当前信息保持原位。照片列表反馈也采用浮动提示。

## Wi-Fi 弹窗

打开后扫描可见2.4 GHz网络，按信号强弱显示；可重新扫描或手动输入隐藏SSID。网络列表固定区域内滚动，标题和底部操作始终可见。

密码输入框始终显示。已保存网络留空保留原密码，输入则替换；新加密网络要求输入密码；开放网络使用无密码选项。原密码不返回页面。

## 时间、容量与文案

- 日期时间统一为设备时间 `YYYY-MM-DD HH:mm:ss`，来源为设备RTC，不用电脑系统时间替代。
- Header、网络卡片时间、运行时长、换图和校时倒计时按秒更新；状态每5秒请求一次。
- 时长省略零单位：900秒显示“15分钟”，3630秒显示“1小时30秒”。
- 容量按KiB/MiB/GiB展示，SD显示已用比例；内部RAM、PSRAM和Flash分别展示。
- 文案陈述实际来源和行为，多句话按句号分行，句内不添加人工换行。

RTC无效、UTC未确认或断线时，设备时钟显示“—”。无效任务显示“—”，停用任务显示“未安排”。

接口见[HTTP状态与控制](http-status.md)、[SD照片API](http-files.md)。历次布局调整保存在[历史记录](history/web-layout-changes.md)。

## 照片导入进度（0.17.0）

上传面板支持 JPEG、PNG 和24位 BMP。批次按单张上传、转换、索引顺序执行，上传按字节显示进度，随后显示转换阶段、百分比和耗时。设备忙或临近报时/轮播时先等待可上传窗口。失败后保留失败及尚未处理的选择项，已成功文件不重复上传；同名主体冲突在上传前拒绝。刷新页面可读取本次启动最近转换任务的进度。

0.17.1 起单张原图上限为8 MiB（8388608字节）。页面在开始传输前检查所选批次，超过上限时保留选择并显示大小错误，不发送原图。

0.17.2 增加PNG选择、签名校验和image/png上传，解码阶段统一显示“图像解码”。PNG的透明像素合成白底，动画PNG不接收。

## 照片点播（0.17.3）

照片卡片新增独立一行的“显示此照片”主按钮，预览、下载、删除在下一行。当前设备照片标记为“当前照片”，不能重复点击；格式不合格的文件禁用显示按钮。请求后固定按钮区域显示“正在显示…”，等待控制任务完成后显示浮动结果提示，不重排卡片。报时和刷屏期间按既有忙碌策略处理。

## 上传前构图确认（0.17.4）

上传按钮改为“确认构图并上传”。弹窗的头部、文件名/张数和底部操作固定，中间为预览与控制区域；窄屏上下排列，控制区域可独立滚动。预览按目标屏幕比例，默认全图留白。右侧提供旋转、显示方式、缩放及重置，铺满时拖动照片调整位置。上一张保留已选构图，最后一张确认才开始整批传输。仅右上角X和取消按钮取消，Esc及遮罩不关闭。不同照片之间释放上一张的浏览器解码图像，构图参数仅保留在本次确认流程中。

## 相框摆放方向（0.17.5）

相框摆放选择横放、向右竖放、向左竖放与倒置，预览画布立即切换800×480或480×800；独立的照片旋转按钮只旋转来源图。下一张未检查的照片沿用最近选择的相框姿态，已检查的照片保留独立设置。重置本张恢复照片旋转/留白/裁剪，保留当前相框姿态。

## 上传重名提示（0.17.6）

重复文件在进入构图弹窗前检查，通过固定位置的浮动提示显示“相册中已存在〈文件名〉”，并说明更改原文件名或先删除旧照片。保留文件选择，不显示0/1完成统计。并发或预检查之后产生的冲突也使用同一中文提示；SD路径错误单独提示。

## 页面内另存命名（0.17.7）

构图弹窗右侧首项为保存文件名输入框和固定.bmp后缀，下方预留校验反馈区域。重名时建议未占用名称，用户可直接编辑；非法名称或重名禁用下一张/确认。前后浏览保留各张名称，重置构图保留名称和相框姿态。窄屏控制区独立滚动，底部操作保持可见。0.17.6的构图前阻断提示由此取代。
