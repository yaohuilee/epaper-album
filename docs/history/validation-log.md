## Windows 构建与桌面测试

- Windows 原生 ESP-IDF v5.5.3，Xtensa GNU 14.2.0；没有使用 WSL。
- `./tools/Build.ps1` 构建通过。应用 383616 字节，bootloader 22272 字节，分区表 3072 字节。
- 16 MB Flash、8 MB Octal PSRAM、240 MHz CPU、USB Serial/JTAG、main 栈 16384 字节。
- `./tools/Test.ps1`：MSVC 14.41，`/W4 /WX /std:c11`，三个程序编译和运行成功。
- 日历与 CRC 原有测试通过；相册测试 843 项检查通过；生产 runtime 配合模拟时钟/显示/NVS 的测试 55 项检查通过。

相册测试覆盖四种旋转、像素颜色/尺寸/格式错误、自然排序、非法/重复/过深 JSON、越界路径、未实现功能启用拒绝、非递归扫描、禁用相册、两种播放策略、随机 50 轮不重复及每张跨重启恢复、失效身份回退、全部坏文件停止。

runtime 测试覆盖刷新完成才计时、深睡截止时间保留且不重复写 NVS、冷启动重新计时、刷新失败不提交位置/不重置截止时间、中断刷新恢复、有效配置缓存回退及手动完整间隔。

- 单独初始化新 `album_state` 分区，烧录 bootloader、分区表和应用；写入校验通过。

## 0.3.1 USB 调试保活 / 充电状态（2026-10-10）

- Windows 原生 ESP-IDF v5.5.3 构建通过，应用 931440 字节。日历/CRC 测试及新增 AXP2101 状态解码、USB 连接/断开/重连与3秒确认期测试通过；相册854项、runtime58项检查仍通过。
- 核对 COM5 MAC，更新前备份 `album_state`，只更新 bootloader、分区表及应用，烧录哈希验证通过；保留SD配置、60张照片、播放位置和UTC校时标记。
- 电脑 USB 模式实测保持唤醒超过60秒，没有发生原10秒空闲深睡；记录 `USB host active`。电源读到 `VBUS=1 battery=1 direction=charging phase=constant-voltage raw=38/33`。
- 电池模式：用户拔USB等待30秒再接电脑KEY唤醒，记录 `deep_wake=1`，上次真正睡眠条件为 `USB host=0 VBUS=0 battery=1 direction=2 phase=5`，即电池放电、未充电。
- 充电器模式：用户接普通充电器并KEY唤醒、等待30秒，再接电脑KEY唤醒。记录 `deep_wake=1`，上次睡眠条件为 `USB host=0 VBUS=1 battery=1 direction=1 phase=3`，证实外部供电且恒压充电时仍进入深睡。
- 两种深睡唤醒均保留原自动换图截止时间、没有重新刷新同图，没有重复联网NTP。接回电脑后再次进入USB调试保活。
- 第一轮电池测试期间出现BOOT换图，30秒刷新尚未结束便重新接回电脑，该轮未作为电池深睡通过证据；在换图完成后重复测试获得上述结果。

未测电脑挂起、USB集线器及各种线材组合，未测调试保活功耗或深睡电流。已深睡后插电脑USB不能自动唤醒，需先按KEY。PWR硬件关机路径未修改。详见 [USB与充电状态](../usb-power.md)。
