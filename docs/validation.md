## 最近完整流程：0.14.35

- Windows ESP-IDF构建和应用区烧录哈希校验通过。桌面相册909项检查、运行时943项检查通过，基础日历/CRC、供电和配网画面测试通过。
- 本机Qwen Image 2.1生成100张1280×768风景图，转换为800×480六色24位无压缩BMP。每张1,152,054字节，100个SHA-256不同，固件BMP解码器全部通过。
- 原6册60张照片先经HTTP完整备份，随后通过API删除照片/空相册。新建5册，各20张；100张上传后完整下载比较SHA-256全部一致。
- 5册全部启用，间隔900秒。下一张控制由001_guilin切换到002_huangshan，索引仍100张，控制/索引无错误。首页和照片库返回HTTP 200。
- 上传响应超时、下载截断和服务器接收超时在流程中实际出现，处理后完成替换；只读重试及明确丢弃部分文件后的上传重试通过真实HTTP模拟测试。

完整操作与本地数据分工见[全球相册流程](world-album-workflow.md)。100张覆盖电脑转换预览检查，本轮没有逐张重新目视核对真机颜色。

## 验证范围

| 项目 | 已有证据 | 边界 |
|---|---|---|
| 硬件 | MCU/存储、PMIC、RTC、SHTC3、屏幕、音频链路及按键探测 | 未确认所有丝印；不等于所有正式驱动已实现 |
| 播放与恢复 | BOOT换图、KEY唤醒、定时换图、PWR开关机恢复真机验证；顺序/随机/错误回退桌面覆盖 | 桌面覆盖不等于所有故障真机注入 |
| Wi-Fi/RTC | 联网校时、UTC写入/读回，Web设置与同步 | 外部RTC全断电保持、IRQ和长期精度待测 |
| 配网 | 手机热点连接、自动配网页、列表和保存；新地址真机通过 | 30秒保留期的单独手机复测未在旧日志补齐 |
| 供电 | 充电器无USB主机仍在线；拔电离线、KEY恢复Wi-Fi/Web | 电池深睡通过网络现象观察，未读取原始复位原因或测电流 |
| 网络照片维护 | 列表、创建/删除空相册、上传/下载/删除和100张回读 | 满盘、掉卡和真实断电持久化未完整验收 |
| 界面 | 页面脚本、布局、弹窗、预览、时间与状态显示的逐版本记录 | 不是所有手机/浏览器兼容性测试 |

## 待测项目

深睡电流、实际电池容量与续航、低电量阈值；长期轮播；真实SD/NVS故障和断电恢复；外部RTC所有供电移除后的保持及报警线路；未来音频播报和活动检测。

验收记录按当时版本保留，历史页中的“当前固件”“当前照片”等只描述当次测试。当前支持范围以[项目首页](../README.md)和[后续计划](roadmap.md)为准。
