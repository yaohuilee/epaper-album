> 历史M0–M4阶段计划，勾选状态对应当时记录。当前状态见[后续计划](../roadmap.md)。

## M0：项目规格

- [x] 私有项目的功能范围、硬件摘要和文档结构
- [x] 全局配置与相册清单示例
- [x] BMP、报时、睡眠及错误处理约定
- [x] 相册 Review：默认逐相册播放、手动换图重置间隔、完整重启恢复照片并重新计时
- [ ] 与用户确认默认换图、静音时间及按键交互

## 基础框架（已完成）

- [x] 固定 ESP-IDF v5.5.3 与 ESP32-S3 N16R8 构建配置
- [x] 板级 PMIC/I2C、屏幕 SPI、SD 挂载和按键事件代码
- [x] RTC 日历读取、SHTC3 读取与 CRC 校验
- [x] 有界 config.json 读取、封装验证及明确的未实现接口
- [x] Windows 原生开发脚本、日历/CRC 独立 C 测试
- [x] 首次新固件上板：PMIC、SD、RTC/SHTC3、显示与按键

## M1：最小离线相册

- [x] 固定 ESP-IDF 版本与依赖，搭建 ESP32-S3 N16R8 可复现构建
- [x] PMIC、SDMMC、SPI/EPD 初始化与故障超时
- [x] 实现配置校验、相册索引、六色 BMP 检查和显示
- [x] BOOT 下一张、定时轮播与睡眠恢复
- [ ] 验收两个相册、禁用相册、顺序/随机、空目录、坏 BMP、配置错误、重启位置恢复
- [ ] 验收默认逐相册完整播放及可选 round_robin，确认两种策略的顺序与间隔
- [ ] 验收手动换图成功后重新计时，失败不错误提交显示位置或重置计时
- [ ] 验收关机后恢复上一张并开始完整间隔，不追补关机期间的换图
- [ ] 验收正常定时深睡唤醒保持原截止时间，照片删除/相册禁用后的回退及随机队列恢复
- [x] 在烧录前备份并校验设备现有 Flash；保留串口恢复路径

## M2：离线报时和温湿度

- [x] 外部 RTC 经 NTP 校时、UTC 迁移与读回验证（0.3.0）
- [ ] 串口手动校时及自动报时中的 OS/无效日历降级
- [ ] SHTC3 CRC、错误降级与传感器自热观察
- [ ] 生成/取得许可清楚的音频片段并在目标硬件验收 16kHz PCM 播放
- [ ] 00/30 分、夜间静音、手动报时、去重与校时跳变
- [ ] 验收跨天、静音起止、重启不重复、刷屏跨报时点、缺音频/传感器失败

## M3：功耗与稳定性

- [ ] 明确各电源轨的安全关闭顺序；比较深睡与监听模式
- [ ] 用测量仪器测电流、真实容量和续航，确定低电量阈值与滞回
- [ ] 长时间轮播、SD 故障和低电量恢复；检查看门狗与文件持久化
- [x] Wi-Fi 周期 NTP 校时、失败重试、结束关闭网络（0.3.0）
- [ ] 可选维护模式

## M4：可选声音活动检测（待定）

- [ ] 与用户选择常在线或允许漏检的周期采样模式
- [ ] 双麦能量、基线、迟滞、消除自身播报触发
- [ ] 比较电视/风扇/安静有人等误判场景
- [ ] 实测功耗，评估是否值得启用；默认仍关闭

M1 代码、桌面测试和部分上板验证已完成，具体证据见 [验证记录](../validation.md)。其余 M1 验收项需要区分桌面覆盖和硬件实测，不把桌面结果等同硬件长期稳定性。M2–M4 中的 RTC UTC 迁移和周期 NTP 已提前实现，其余功能继续按阶段推进。
