# Web 控制台布局（0.11.3）

[English](../../history/web-layout-changes.md) | 简体中文


> 历史记录：保留当时的实现、界面和验收描述，不作为当前操作指南。
> 当前说明见[文档首页](../README.md)，归档目录见[历史索引](README.md)。

统一采用顶部 Header、左侧 Sider、右侧工作区结构。参考 [Ant Design Layout](https://ant.design/components/layout/) 和 [24 列 Grid](https://ant.design/components/grid/) 的层级、间距与栅格思路，使用内置 HTML/CSS/JavaScript 实现，页面没有外部资源依赖。

顶部64px，显示品牌与连接状态；左侧224px，提供最多两级的操作菜单。当前入口以浅蓝底色、文字颜色与左边线标识，折叠菜单保留父级提示。右侧包含面包屑、标题、说明和当前工作区，使用24列CSS Grid；标准卡片跨12列，工具栏/表单/照片库跨24列。照片卡在不同宽度下跨6、8、12或24列。间距以8px为基础，常规 gutter 为24px。

| 一级菜单 | 二级入口 | URL |
| --- | --- | --- |
| 设备管理 | 设备概览 | `/#overview` |
| 设备管理 | 网络与时间 | `/#network` |
| 设备管理 | 环境与供电 | `/#environment` |
| 相册管理 | 照片库 | `/albums#photos` |
| 相册管理 | 播放设置 | `/#playback` |

`/` 默认进入设备概览，`/albums` 默认进入照片库，兼容原访问地址。hash切换支持地址分享、刷新和浏览器前进/后退。播放设置保留原有多选相册和统一间隔表单。照片库合并浏览和上传，不再提供独立上传菜单。设备状态每5秒刷新，但不重置展开菜单和当前焦点。跨页面入口在提交或传输进行中被阻止，避免丢失操作结果。未提交的选择在离开当前HTML页面时不持久化。

767px及以下以Header按钮打开左侧抽屉，支持点击遮罩或Esc关闭，内容卡片切换为单列。操作按钮包含禁用、错误和进度提示，原BMP校验、确认删除、索引等待与SD保存行为保持。共享资源为 `/ui.css` 和 `/ui.js`，均从固件提供并使用 no-store，升级后不会混用旧版布局资源。

照片接口、使用限制及网络休眠行为见 [文件API](../http-files.md)；播放设置见 [状态页](../http-status.md)。

各工作区的刷新按钮统一放在顶部标题右侧，使用次要按钮样式；窄屏保持同一行，标题说明可以换行。状态页刷新设备信息，照片库刷新相册及文件列表，原有禁用条件与操作行为保持一致。

## 相册资源管理器

相册管理只保留“照片库”和“播放设置”两个入口。照片库根视图以文件夹卡片展示已配置相册，显示SD目录、相册ID与轮播状态；点击文件夹打开照片列表。工作区使用资源管理器式工具栏（返回上级、相册地址栏、上传照片）、名称筛选、文件区和分页，始终复用标题右侧刷新按钮。

打开相册后，照片以BMP文件卡片展示文件名、大小与头部校验结果，提供预览、下载、删除操作。点击“上传照片”在同页展开多文件选择/拖放面板，显示目标相册路径；收起面板保留选择，切换相册会清空待上传文件以免上传到错误目录。刷新保留当前相册与页码。忙碌时禁用文件夹及上传操作，文件更新仍使用原API和索引等待逻辑。

目录地址为 `/albums#photos`，相册地址为 `/albums#photos/相册ID`（URL编码），支持直接访问及浏览器前进/后退。旧的 `/albums#upload` 进入合并后的照片库根视图。该浏览器只展示配置清单内的相册及BMP照片，不提供新建/删除相册目录功能。

窄屏地址栏独占一行，相册文件夹保持两列、照片卡片一列，上传面板和筛选栏适配工作区宽度。文件图标不自动读取原BMP，按需点击预览，避免同时下载多张约1.1MiB的照片。

相册操作反馈采用右上角固定浮动消息，不参与工作区栅格，因此出现、关闭和自动消失不改变列表位置。普通提示5秒后在非忙碌状态自动隐藏，错误保留至关闭或下一条消息，并支持手动关闭。文件卡片的“格式与尺寸检查通过”只代表BMP结构、目标尺寸与长度检查通过；悬停说明明确逐像素六色校验在上传或解码阶段进行。

播放设置分为正在播放、相册多选、停留时间和保存区。相册选择提供全选/清空及选择数量，间隔提供5/15/30分钟、1小时、1天快捷值，以及秒/分钟/小时/天自定义单位，最终按整数秒调用原设置API。有效范围仍为120秒至7天；有修改且有效时才允许保存，支持撤销回设备当前设置。定时刷新保留草稿，设备忙碌或离线时禁用操作。容量达到1GiB时显示GiB，并展示已用比例（总量减可用量，占总量的百分比）。

0.11.0：换图按钮移至两页共用的侧栏底部，显示忙碌/完成状态。播放设置仅保留两张独立保存卡片：相册选择采用自动多列、最高420px的列表区（手机360px），轮播间隔单独保存。每张卡片有自己的撤销、保存和草稿状态；保存时仅提交该字段，另一张卡片的草稿不提交也不清空。间隔保存作用于已保存的启用相册，相册选择保存保留每个相册各自的间隔。

两张设置卡片的保存按钮固定在标题右上角，统一显示“保存”，无障碍名称区分保存相册选择和保存轮播间隔。撤销与草稿状态保留在卡片底部，原独立提交和禁用条件不变。

0.11.2：撤销与保存并排放在卡片右上角，草稿状态紧随标题。移除卡片底部操作栏和结果占位；保存过程/结果使用右上角浮动提示，成功自动隐藏，失败保留可关闭，不推动设置内容。

0.11.3：按工作区实际可用宽度响应（CSS容器查询），达到900px时两张设置卡片等宽并排，否则上下排列；卡片高度由内容决定，不拉伸出额外空白。卡片内部保留相册自动多列及标题右上角操作。

## 网络设置弹窗（0.14.1）

“网络与时间”工作区保留 Wi-Fi、RTC 和校时状态卡片，操作按功能归到卡片右上角：Wi-Fi 网络提供设置和刷新，RTC 与网络校时提供校时设置、立即同步时间和刷新。两份配置表单分别放入原生 modal dialog，点击入口才显示，不占主页面布局高度。撤销和保存位于弹窗底部右侧，各自独立提交；保存任务成功后关闭弹窗并显示浮动结果，失败保留弹窗和草稿。

通过右上角关闭图标退出；Esc 和点击遮罩不关闭；退出不会提交，草稿在当前页面内保留，后台状态刷新不覆盖未提交内容。撤销恢复设备当前值，重新加载整个页面会清空草稿。弹窗打开时背景不可操作且停止背景滚动，焦点由原生 dialog 管理。提交进度及错误提示放在当前弹窗内，关闭后恢复全局浮动消息，避免被原生 top layer 遮挡。桌面字段左右分栏，手机改为单列，长内容在弹窗内部滚动。

## 统一对话框模式（0.14.2）

Wi-Fi 设置、校时设置、照片预览、删除确认共用 dialog-header / dialog-footer：只保留一个标题，右上角为无外框的关闭图标，底部操作按钮靠右排列。设置弹窗保留撤销和保存，预览提供关闭，删除确认提供取消和确认删除。长内容内部滚动，标题和底部操作区保持可见。

所有对话框设置 closedby="none"，并通过共享 cancel 事件 preventDefault 兼容禁用 Esc 关闭；不提供遮罩点击关闭处理。只能通过明确的关闭/取消操作或任务成功完成关闭。输入草稿、独立保存及照片删除流程保持原有语义。

## 网络卡片操作归类（0.14.3）

“网络与时间”工作区顶部不再放操作按钮。Wi-Fi 网络卡片右上角提供 Wi-Fi 设置、刷新；RTC 与网络校时卡片右上角提供校时设置、立即同步时间、刷新。两个刷新入口共用状态读取接口，更新设备状态快照。其他工作区仍在标题右侧刷新。

卡片标题栏在宽度不足时自动换行，按钮组保持右对齐。后台每5秒刷新时复用操作按钮及事件处理，保留按钮的键盘焦点。首次读取失败仍显示对应卡片和刷新入口，便于重试连接。

## 播放设置摘要与弹窗（0.14.4）

播放设置工作区保留两张响应式卡片：参与轮播的相册、照片停留时间。卡片仅显示设备当前已保存设置，右上角的设置按钮打开各自独立弹窗；相册摘要显示启用数量和相册名称，间隔摘要显示当前已保存时长。若启用相册的间隔不同，则明确显示分别设置的时长。

编辑控件、快捷间隔、全选/清空移入弹窗，撤销和保存位于底部右侧。单标题、无边框关闭图标、禁用 Esc/遮罩关闭沿用统一规则。关闭不提交，未提交草稿保留；各弹窗只提交自己的字段，保存一个不清除另一份草稿。保存成功自动关闭并更新摘要，失败保留草稿及提示。摘要始终来源于状态接口，不使用未提交输入值。

相册摘要和选择区均限制高度、内部滚动，适应较多相册；设置卡片在工作区宽度达到900px时并排，窄屏堆叠。

## 提示文案与短句排版（0.14.5）

页面、卡片和弹窗的说明采用事实陈述。删除重复的操作引导、解释性比喻及未测量指标的推算描述，保留实际来源、格式限制、保存行为和状态有效范围。

多句提示按中文句号分成独立行，句内不添加人工换行。短句使用 text-wrap:pretty，宽度不足时自然折行。renderFacts 使用 textContent 创建 fact-line 元素，不解析说明文字为HTML；静态提示和每次刷新生成的状态卡片均使用同一规则。容量、时间、状态和接口行为不变。

## 简洁时长（0.14.6）

运行时长、照片停留间隔、换图倒计时、校时周期、失败重试间隔、超时及下次校时倒计时共用时长格式。按天、小时、分钟、秒排列，省略数值为0的单位，不插入空格；900秒显示15分钟，3630秒显示1小时30秒，86400秒显示1天。零时长显示0秒，缺失或无效值显示—。日期、北京时间和更新时间保留原格式。

## 统一日期时间（0.14.7）

RTC 北京时间、最近校时尝试、最近校时成功及各状态工作区的更新时间统一采用 YYYY-MM-DD HH:mm:ss。固定北京时间 Asia/Shanghai、24小时制，月日时分秒补齐两位，午夜为00:00:00。时长继续使用0.14.6的简洁单位格式。无记录与无效状态保留原提示，API时间戳与RTC UTC存储不变。

## Header 设备时钟（0.14.8）

所有工作区的 Header 右侧共用设备 RTC 时钟，格式 YYYY-MM-DD HH:mm:ss，显示北京时间。状态请求成功后用 RTC UTC 快照和响应中的快照年龄校准，浏览器以单调计时器推进，每秒渲染；状态轮询保持原有5秒周期，不增加每秒网络请求。后台或忙碌导致定时器延迟时按实际经过时间追赶，下一份快照重新校准。

RTC无效、UTC未确认或状态读取失败时显示—，不使用电脑当前时间替代。时钟不设实时播报区域，数字使用等宽位数避免走时引起宽度抖动。窄屏Header将时间和在线徽标上下排列，保留完整单行时间。共享UI脚本在工作区脚本之前加载，确保首次状态响应即可更新Header。

## 网络卡片同步走时（0.14.9）

网络与时间卡片中的北京时间与Header共用data-device-clock标记和同一设备时钟。每次秒级更新只计算一次时间，再同步写入所有时钟节点，显示文本及datetime一致。状态卡片重建后立即由同一状态校准时钟。设备断线或RTC无效时，两处均显示—；最近尝试及最近成功记录仍为固定事件时间。

## 秒级任务倒计时（0.14.10）

下次换图与下次自动校时使用共享秒级计时器、状态快照剩余秒数、快照年龄及浏览器单调经过时间更新。状态刷新后重新校准任务剩余时间，倒计时格式与所有其他时长共用formatDuration，省略零单位。后台暂停导致定时器延迟时按经过时间扣减。到期下限为0秒，实际任务仍由设备调度执行；页面不触发额外任务。

任务停用或自动播放停止显示未安排；缺失/无效剩余时间或断线显示—。RTC无效不会阻止有效任务倒计时。切换工作区及状态卡片重建后继续校准，无新增网络轮询。

## 秒级运行时长（0.14.11）

设备概览的本次运行使用data-uptime节点，由共享秒级计时器更新。设备uptime_seconds加状态快照年龄及浏览器单调经过时间计算本次启动的运行时长，沿用formatDuration省略零单位。状态刷新和设备重启时按新的运行时长校准；断线或无效值显示—。运行时长不依赖RTC有效性，不增加状态轮询频率。

## 状态更新时间来源（0.14.12）

设备概览、网络与时间、环境与供电和播放设置的状态已更新时间，使用本次状态响应校准后的Header设备RTC时间，格式仍为YYYY-MM-DD HH:mm:ss，不读取电脑系统时钟。时间记录在状态读取成功时固定，下一次读取成功后更新；Header继续秒级走时。RTC无效时记录显示—，状态读取失败仍显示原失败提示。照片库现有列表反馈不新增时间字段。

## 侧栏底部操作区对齐（0.14.13）

底部换图区域与导航菜单共用左右边界，移除额外16px水平缩进。按钮填满菜单宽度，高度36px；相册/操作状态和换图提示统一居中。区域采用纵向flex及8px间距，状态行最小高度36px容纳两行文本，移除段落默认外边距，减少状态与提示间的空白。长状态允许自然换行，区域保留顶部细分隔线及16px内间距；换图逻辑、按钮禁用和状态播报不变。

## 侧栏换图倒计时（0.14.14）

所有页面的侧栏底部用下次换图倒计时替换墨水屏换图耗时提示。data-countdown=photo与设备概览共用共享秒级计时器、设备剩余时间、快照年龄及简洁时长格式；同一状态页两个位置始终同步。未安排、断线和到期显示沿用原倒计时规则，不增加状态轮询或主动触发换图。保留居中对齐和现有间距。

## 侧栏相册与倒计时标签（0.14.15）

侧栏底部固定展示当前相册、下次换图两行信息。两行共用side-meta：字号12px、行高18px、48px标签列、8px列间距；标签左对齐、值右对齐，两行间距8px。长名称允许换行，相册名称通过textContent写入。换图进度和错误保留在独立sidebar-action状态行，非空才显示，不替换相册名称。断线时相册名称显示—，倒计时仍由共享规则更新。

## 当前照片与固定切换提示（0.14.16）

侧栏增加当前照片，取设备当前照片路径的文件名，与当前相册及下次换图共用标签列、字号和间距。相册名称及照片文件名均单行省略显示，title保留完整内容，空值显示—。名称通过textContent写入，避免解析为HTML。

切换提示始终保留36px两行高度，内容为空时保留空间；长错误信息限制为两行，title保留全文。提示出现、更新和清空不改变按钮及三行信息的位置。请求发送及等待新任务进入状态快照时继续显示进度，不被旧快照轮询清空。换图及倒计时任务逻辑不变。

## 侧栏当前照片预览（0.14.17）

当前照片文件名为可聚焦按钮，保持单行省略及完整名称title，点击读取/api/photo并打开照片预览弹窗。请求使用当前播放相册ID、文件名及设备令牌，与照片库采用同一原始BMP预览。状态页与照片库共用photoPreview控制器，统一单标题、无边框关闭图标、底部关闭按钮、禁止Esc/遮罩关闭及图片缩放布局。

侧栏预览立即显示读取状态，失败在弹窗内提示；设备忙碌、离线、无当前照片或上传等操作期间不发起新的预览。关闭时取消未完成请求、清理图片地址；过期请求不会重新打开弹窗，设备令牌变化时关闭旧预览。照片库预览读取与重试流程保持原有接口，共用图片显示和资源清理。

## 换图按钮与预览占位（0.14.18）

换图请求和执行进度显示在侧栏按钮上，按钮固定36px高度。执行成功后恢复“切换下一张”；失败时按钮显示重试入口，悬停显示错误详情。删除独立状态行及其预留空间，当前相册、照片和倒计时保持原位。

两页共用的照片预览弹窗预留800×480比例的图片区域。读取提示居中显示在占位区域内，照片解码完成后隐藏提示。图片以contain适配同一区域；读取失败保留占位并显示错误。弹窗宽度850px，受视口宽度约束。

## 一屏照片预览（0.14.19）

预览弹窗按窗口宽高确定可用尺寸，使用纵向弹性布局：标题与X、文件名、图片区域、来源文字。图片区域占据剩余高度，object-fit:contain完整显示原图，读取提示沿用同一区域。移除底部关闭按钮，仅由右上角X显式关闭；Esc和遮罩关闭规则不变。文件名为单行省略，悬停显示完整名称。图片加载和窗口缩放均不产生弹窗内部滚动条。

## 相册预览导航（0.14.20）

预览左右箭头按当前预览相册的自然排序浏览BMP，并在文件名旁显示序号/总数。首张禁用上一张，末张禁用下一张；单张相册两侧禁用。列表按100项分页读取至相册结束，导航不受照片库当前页或筛选条件限制。

侧栏入口使用设备当前相册；照片库入口使用所选文件夹相册。弹窗打开后保存独立预览位置，状态轮询不改变该位置。导航只调用GET /api/files与GET /api/photo，不调用设备播放控制或写入配置。读取期间禁用箭头，关闭取消请求，过期响应不会再次打开弹窗。失败时保留原预览位置并显示错误，可再次点击箭头重试。

## Wi-Fi 扫描选择（0.14.21）

Wi-Fi设置弹窗打开后自动扫描，顶部可重新扫描。列表按信号强弱排序，以SSID与认证方式去重，显示名称、RSSI、信道及是否加密。桌面两列，窄屏单列，列表限制高度。点击网络填入SSID：新加密网络要求设置密码，无密码网络选择无密码；当前网络保留原密码。名称输入框可填写隐藏网络。选择与输入只修改草稿，保存并连接沿用既有独立保存与失败恢复流程。扫描期间禁止重复扫描或提交保存，关闭弹窗取消页面等待，设备已接受的扫描仍可完成。

## Wi-Fi 弹窗固定布局与密码输入（0.14.22）

弹窗固定头部和底部撤销/保存操作区，整体不滚动。网络列表填充中间剩余空间并独立滚动，扫描或选择网络不改变列表区域高度。窄屏凭据上下排列；低高度横屏列表和凭据左右分区，极小窗口仅凭据区域允许滚动，操作区始终保留。反馈为弹窗内浮动提示，不挤占列表和操作区。

密码输入框始终显示，不再由密码处理方式下拉框展开。当前已保存网络密码留空保留；输入则替换。选择新加密热点清空密码并聚焦既有输入框，输入有效密码后才能保存。无密码网络使用固定复选框并禁用密码输入框。手工输入未保存的隐藏SSID同样要求密码，或显式选择无密码。原密码不返回页面，保存协议及失败恢复流程沿用原实现。
