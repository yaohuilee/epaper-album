# 语言支持

[English](../language-support.md) | 简体中文 · [文档首页](README.md)

## Web 界面

0.18.0 支持 `en` 和 `zh-CN`，覆盖状态控制台、照片库、构图、预览、声音与报时及离线配网页。通过 Header 的“Language / 语言”选择 English 或简体中文。

首次访问跟随浏览器语言：中文浏览器使用简体中文，其他语言使用英文。已保存偏好优先；URL 中的 `?lang=en` 或 `?lang=zh-CN` 可明确指定。导航链接保留语言参数，受限存储环境也可继续使用。

偏好仅保存在当前地址的浏览器 localStorage，键名为 `epaper.language`，不写 SD 或 NVS。配网地址和家庭网络地址属于不同来源，偏好分别保存。语言切换重新加载当前路由，清空未保存的页面草稿。弹窗打开或页面操作进行时禁用切换；关闭弹窗或结束操作后可切换。切换不提交设备配置、不改变当前照片或计划，也不重启设备。

初始文档的标题、标签和辅助属性在应用脚本执行前翻译，动态消息在生成时使用同一内置目录。`/i18n.js` 不依赖 CDN 或在线翻译。API 地址、JSON 字段、枚举、Wi-Fi 名称、密码、相册名和文件名保留原值。

日期统一为 `YYYY-MM-DD HH:mm:ss`，仍以设备 UTC+8 时间为准。简洁时长省略零单位：中文为“15分钟”“1小时5分钟”“0秒”，英文为 `15 min`、`1 h 5 min`、`0 s`。语言不改变时区。

## 墨水屏与语音

配网墨水屏增加固定中英文说明，二维码内容和热点地址不变。浏览器偏好无法改变尚未联网的屏幕，因此使用双语固定文字。照片本身不翻译。

ESP-TTS 小乐仍为中文音库，时间、温湿度和异常播报保持中文。英文语音尚未实现。串口诊断和协议错误码保留技术原文。

## 仓库与维护

README、默认 docs 目录和根目录政策文档为英文。中文文档位于 `docs/zh-CN/` 的对应路径，根文档使用 `.zh-CN.md`。各页提供另一种语言入口。许可原文不翻译替换；英文历史记录按版本整理，原中文完整时间线保留。

新增界面文字时同步更新 `components/services/i18n.js`，动态文字使用 `__t()`，不得翻译协议或用户数据。执行 `node tests/i18n_test.cjs` 检查语言、目录、辅助属性、时长和英文上传路径；执行 `python -X utf8 tools/check_docs.py` 检查链接和文档对应关系。原有回归测试及桌面/窄屏布局检查继续保留。
