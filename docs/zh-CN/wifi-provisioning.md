# 离线 Wi-Fi 配网

[English](../wifi-provisioning.md) | 简体中文


[文档首页](README.md) · [项目首页](../../README.zh-CN.md)

`POST /api/wifi-provision` 可从已联网状态主动进入配网，使用同一控制令牌和 JSON 空对象，返回202异步任务；KEY 长按不依赖网络。

设备在首次启动没有有效 Wi-Fi 配置，或长按 KEY 至少 2 秒后松开时，进入配网模式。正常电池定时唤醒且未到校时期限时，不额外尝试联网。

已保存 Wi-Fi 配置的设备不会因连接失败、断网或 NTP 校时失败自动进入配网。相册继续使用 SD 卡照片和设备 RTC；外部供电时，Wi-Fi 连接失败后等待 60 秒再重试，刷屏或报时期间顺延，校时按配置中的失败重试间隔执行。连接尝试受配置中的连接超时限制，可能短暂延迟主循环处理。网络恢复后 Web 服务重新开放。更换网络或修改密码时，可长按 KEY 手动配网。

## 操作

1. 墨水屏显示开放热点 `epaper-album-XXXXXX`，后六位来自设备 MAC。热点没有密码。
2. 手机连接热点，获取 `192.168.7.x` 地址。设备地址为 `http://192.168.7.60/setup`。
3. 左侧二维码为 `WIFI:T:nopass;S:epaper-album-XXXXXX;;`，用于连接热点。右侧二维码为配网页面地址。
4. 支持系统联网探测的手机可自动显示配网页面；手机行为各异，未弹出时扫描地址二维码或手动打开地址。
5. 选择可见 2.4 GHz 网络，或输入隐藏网络 SSID。密码字段始终显示；已有网络可留空保留已保存密码，无密码网络需勾选对应选项。
6. 点击“保存并连接”。成功后页面显示新地址，热点继续开放 30 秒，随后关闭并恢复原照片。失败时恢复原 SD 配置，热点保持开放，可继续修改。

## 运行与持久化

- AP+STA 模式允许扫描和尝试连接时保留配网热点。STA 与 AP 共用射频，连接时热点可能调整信道，手机可能短暂重新连接。
- 配网期间停止自动换图、暂停校时任务并阻止深睡；普通 BOOT 换图和其他配置命令不执行。PWR 硬件关机仍有效。
- `/` 在配网模式显示配网页面，未知 HTTP 路径返回 302 到固定配网地址。DHCP 提供热点 DNS 地址和 option 114；`/api/captive-portal` 返回 `application/captive+json` 及配网页面地址。DNS 对有效的 IN/A 查询返回热点地址，其他类型返回空答案；不拦截 HTTPS。
- 配网页面复用 `/api/status`、`POST/GET /api/wifi-scan` 和 `POST /api/wifi-settings`。POST 与扫描结果仍需要 `X-Album-Token`。
- 配网模式拒绝照片文件 API 的操作；照片和相册配置不修改。
- Wi-Fi 设置保存到 SD 根配置文件。首次配网同时启用 Wi-Fi 和 NTP，未配置服务器时使用既有大陆 NTP 默认值；配置写入采用现有原子替换流程。
- SD 卡和可读取的相册根配置、清单是保存配置的前提；空照片库可配网。无卡或配置损坏时热点仍可显示，但不能保存配置。
- 刷配网画面前持久标记屏幕内容已改变。成功后强制重绘原照片；中途断电后由既有屏幕恢复机制重绘相册。
- 正常配置后恢复原 USB / 电池 / 充电器运行策略。电脑、充电器或充电宝的USB外部供电保持在线；仅电池供电按事件计划深睡。

二维码使用 [Nayuki QR Code generator](https://github.com/nayuki/QR-Code-generator/tree/master/c) 的 MIT C 实现，版权与许可保留在源码头部。固件按设备 SSID 动态生成两个二维码，不保存网络密码到二维码。

## 验证

`tools/Test.ps1` 覆盖首次配置启用、无密码网络、错误输入、原配置恢复、配网后照片恢复、显示失败时持久脏标记、画面边界和黑白像素。生成的 `.local/provision-frame.bin` 为 800×480、4bpp，可用二维码解码器验证两个负载。手机自动弹窗、实屏扫码和 AP 连接须在实际手机上验证。


## 配网画面与成功结果

墨水屏采用简洁 DOS 风格：顶部蓝底白字标题栏，正文和二维码使用黑白。无彩色方框、步骤标题或编号。二维码保留四模块以上留白。

标题栏仅保留“相册 · 设备配网”，按实际字形边界整行横向居中，移除右侧英文标题。

画面使用8px间距网格：左右边距24px，两列各360px，列间距32px。每列的232px二维码区域居中，说明文字按实际字形边界与二维码横向居中对齐。顶部热点信息、底部提示及网页地址分别作为整行内容横向居中；标签和值间距24px，底部两行间距32px，保留文字基线对齐。

左侧二维码是 Wi-Fi 连接数据，使用手机 WLAN 设置中的扫码入口；支持该数据格式的系统相机也可识别。微信扫码不作为连接热点的操作入口。右侧二维码为标准 HTTP 网页地址，标注微信扫一扫或手机相机；手机须先连接设备热点。微信对局域网链接的处理可能随版本变化，手动地址仍保留。

手机收到本次保存任务成功结果后，页面隐藏热点列表、密码表单及其他配网信息，只显示配置成功、设备 Web 服务地址和同一 Wi-Fi 内可访问的提示。此时停止状态轮询，热点关闭后继续保留成功结果和地址，不覆盖成设备离线提示。

成功页设备地址使用14–18px自适应字号并保持单行；窄屏缩小地址卡片及成功区域的内边距，保留完整可点击地址。

固定文字位图由 `tools/provision_font.py` 生成；已提交生成后的头文件，编译固件不依赖字体或 Pillow。

## 固定热点地址

配网热点使用 `192.168.7.0/24`，设备地址、网关和 DNS 为 `192.168.7.60`，配网页面为 `http://192.168.7.60/setup`。DHCP 自动分配同网段客户端地址。固件的 IP、DNS 回答、HTTP 跳转和屏幕二维码地址集中定义于 `provision_address.h`。连接家庭 Wi-Fi 后的地址仍由家庭路由器分配。

成功页显示配置已保存和热点关闭倒计时。倒计时来自设备实际保留期限，按秒更新；在保留期内刷新页面也会恢复成功页。手机切回设备连接的 Wi-Fi 后可访问设备 Web 地址。

成功后的热点保留时间为30秒，成功页倒计时使用设备实际剩余时间。
